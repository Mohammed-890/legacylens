What runs for real

        

          The Python engine parses source using AST, builds import edges, flags
          five code patterns and retrieves evidence with BM25. A local server
          can run a read-only tool-calling LLM agent when configured.
        

        
What the demo demonstrates

        

          Northstar is a fictional billing service with seeded defects. Its
          repair is a predefined, reviewable patch. Five actual tests are run
          before and after that patch. The hosted site replays recorded results;
          the local app runs them on demand.
        

        
Boundaries

        

          No arbitrary code execution, automatic production changes or
          guaranteed root-cause claims. Import analysis remains in local server
          memory. LLM mode sends retrieved source to your configured provider
          only when selected. The graph represents imports, not measured runtime
          traffic.
